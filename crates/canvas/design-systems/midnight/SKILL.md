# Midnight design system

Use this system when the user picks "midnight" or asks for a dark,
technical or developer-tool look.

1. Read `DESIGN.md` in this folder before writing markup.
2. Create the design with `design_create` and `design_system: "midnight"`:
   it copies `tokens.css` into the design and links it from `index.html`.
3. Use only the CSS custom properties from `tokens.css` for colour, type,
   spacing, radius and elevation.
