# Editorial design system

Use this system when the user picks "editorial" or asks for a magazine,
long-read, portfolio or print-like look.

1. Read `DESIGN.md` in this folder before writing markup.
2. Create the design with `design_create` and `design_system: "editorial"`:
   it copies `tokens.css` into the design and links it from `index.html`.
3. Use only the CSS custom properties from `tokens.css` for colour, type,
   spacing and rules.
